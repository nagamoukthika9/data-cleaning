# Date Cleaning Basics

## Project Overview
This project focuses on cleaning and validating date columns in a Retail Sales dataset using Excel and Python (Pandas).

## Objective
To standardize inconsistent date formats and ensure reliable date handling.

## Tools Used
- Microsoft Excel
- Python
- Pandas

## Dataset
Retail Sales Dataset (Kaggle)

Total Records: 1,000

Date Column: `Date`

## Tasks Performed
1. Imported the retail sales dataset.
2. Checked the Date column for missing values.
3. Parsed dates using the explicit `YYYY-MM-DD` format.
4. Identified invalid date values.
5. Created a standardized `Date_Clean` column.
6. Prepared an issue log to document validation results.

## Validation Results
- Total Records: 1,000
- Successfully Parsed Dates: 1,000
- Missing Dates: 0
- Invalid Dates: 0
- Standard Date Format: YYYY-MM-DD

## Deliverables
- Raw_Data
- Cleaned_Data
- Issue_Log
- Summary

## Conclusion
All dates were already in a consistent format. Pandas validation confirmed that all 1,000 date values were valid. No corrections were required.

This task improved my understanding of date parsing, validation, and data quality management.
